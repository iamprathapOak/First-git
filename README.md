
# Banking Transaction Management System(Java)

  This project is a simple ATM simulation developed using Java.
  It allows users to perform  basic banking operations such as balance inquiry, deposit, withdrawal, and PIN change through a console-based interface.


 ### Key features:
   * **Balance Inquir**: To check the current balance.
   * **Deposit**: To add money to the account.
   * **Withdrawal**: To withdraw money from the account.
   * **PIN Change**: To update the Security PIN.

### Technologies Used:
  * **Java**:Core programming language.
  * **Scanner class**:To get input from the user.
  * **OOPs Concepts**: Leverged **Inheritance** and **Method Overriding** to build new features upon existing ones, ensuring a modular and scalable structure
